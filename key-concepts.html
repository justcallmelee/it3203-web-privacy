Key Concepts

Seven essential ideas for understanding Web 3.0 and privacy

The concepts below build on each other. Reading them in order gives a foundation for the two research topics on this site.

1Web 3.0

Web 3.0 (also written Web3) is the idea of a web built on decentralized networks rather than company-owned platforms. Where Web 1.0 let people read and Web 2.0 let people read and write, Web 3.0 aims to let people read, write, and own their data and digital assets.

2Blockchain Technology

A blockchain is a shared digital ledger made of blocks of transactions linked together by cryptographic hashes. Copies are kept by many computers, so the record cannot be secretly changed by any one party.

3Decentralization

Decentralization means that no single organization controls a system. Decisions and data are spread across many participants who follow shared rules. This removes single points of failure but can make systems slower and harder to govern.

4Digital Identity

In Web 3.0, a person's identity is usually a wallet address or a Decentralized Identifier (DID) that they control with a private key. Instead of creating a new account on every site, the user can reuse one identity and choose what to share.

5Smart Contracts

Smart contracts are programs stored on a blockchain that run automatically when certain conditions are met. They replace middlemen with code, but any bug in that code is public and often permanent.

6Data Privacy and Ownership

Data ownership is the right to control who can access, use, and profit from your information. Data privacy is about keeping that information from being seen by others. Web 3.0 can improve ownership while actually reducing privacy, because public ledgers are visible to everyone.

7Cryptographic Security

Cryptography protects Web 3.0 systems. Public-key cryptography lets users sign transactions with a private key that others can verify with a public key. Hash functions link blocks together, and zero-knowledge proofs allow a claim to be proven without revealing the data behind it.
