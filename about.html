About This Project

This website was built for the IT 3203 class project. It presents research on how Web 3.0 technologies affect digital privacy, security, and user control. The project is completed in three milestones:

  1. Milestone 1: Build the informational site with HTML and CSS.
  2. Milestone 2: Add a JavaScript quiz so visitors can test their Web 3.0 knowledge.
  3. Milestone 3: Make the site fully responsive for mobile devices and finish the research.

The site is hand-coded without templates or frameworks, and all diagrams were created for this project.
